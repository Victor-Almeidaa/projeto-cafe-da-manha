Café da Manhã da Equipe
Sobre o projeto

Aplicação web desenvolvida para organizar o café da manhã dos colaboradores, permitindo registrar quem vai participar, quais alimentos cada pessoa pretende levar e a data do evento.

O objetivo é facilitar a organização, evitar conflitos e permitir que todos acompanhem as contribuições da equipe.

Tecnologias utilizadas:
Angular,
Spring Boot,
Java,
TypeScript.

Inteligência Artificial utilizada:
Bolt,
ChatGPT,
Claude,

Banco de dados:
supabase.

publicado: 
Vercel.

Funcionalidades:
Cadastro de colaboradores.
Registro de CPF.
Cadastro dos alimentos que serão levados.
Escolha da data do café da manhã.
Organização das contribuições.
Visualização dos itens cadastrados.
Cancelamento de itens em caso de desistência

Como executar o projeto:
Acesse a página da aplicação.
Crie sua conta de acesso, cadastrando seus dados e uma senha.
Após realizar o cadastro, faça o login.
Selecione a data do café da manhã.
Descreva os itens que deseja levar.
Adicione os itens à lista.
Os itens cadastrados ficarão disponíveis para visualização na página.
Confirmação dos itens.

Os itens só poderão ser confirmados no dia selecionado.

Cancelamento:

Caso desista de levar algum item, será possível cancelar o registro diretamente na página da aplicação.
